## Portfolio Contents

The portfolio is organized into three main sections:

### Lab Activities

Hands-on exercises and laboratory activities completed throughout the course. These activities focus on understanding and implementing concepts introduced during lectures.

Topics include:

- Understanding Deep Learning
- PyTorch Basics
- Convolutional Neural Network (CNN) Implementation
- Other practical deep learning exercises

### Assignments

Course assignments that apply concepts discussed in class. Each assignment demonstrates the process of applying analytical and computational techniques to a specific problem.

### Projects

Larger-scale applications of data science and deep learning concepts. Projects involve different stages of the data science workflow, including problem formulation, data preparation, analysis, modeling, evaluation, and interpretation.
